# Olesya Portfolio v7 — Dusk + 2D / 3D

Готовая статическая основа для GitHub Pages без сборки

## Просмотр
Распаковать архив и открыть `index.html` в браузере

## Галереи
- `directions/2d/index.html` — 12 роликов, Beach Tours → Portland → YouTube вверху, вертикальные и квадратные ниже, **без длинного Showreel**
- `directions/3d/index.html` — сверху зелёный интерьер и Рассказово, ниже пять дополнительных 3D-видео, ещё ниже пять статичных рендеров
- Видео открываются только по клику в модальном плеере со звуком, скролл не инициирует загрузку всех роликов
- Статичные рендеры открываются крупно в новой вкладке
- Главный бесшумный баннер остаётся на первом экране
- Галерея AI и кейсы остаются заготовками до получения материалов
- Контакты пока не заполнены, перед публичным запуском добавить настоящие ссылки

## GitHub Pages
Можно выложить файлы в корень публичного репозитория и включить Settings → Pages → Deploy from a branch → main / root
Все отдельные видео меньше 25 МиБ, для удобства загрузки через браузер
Оригинальные материалы остаются неизменными, для web-хостинга подготовлены оптимизированные копии
